# ASCII section experiment

Standalone, non-production exploration of the real “Every agent. One shared starting point.” section, inspired by Jordi’s supplied terminal-art references. Open `index.html`, or serve this folder on localhost:4320. Existing hero and landing application are untouched.

Headings, labels, captions, supporting copy and links are native HTML. Connections are SVG. Sparse decorative glyphs are native text. The librarian is a generated raster ASCII-style illustration, not a true text renderer. Logo-like glyphs are explicitly illustrative. Responsive layout switches to a single column below 800px.

Generated with the built-in image tool, exported to `assets/librarian.webp` at 1000px using WebP quality 88. Geist and its license are included locally. Browser checked at the normal preview viewport; no production deployment.

## Final generation prompt

Experimental Zenod section illustration asset. Reference image is the character identity only: mature classical Greek librarian, laurel, curled beard, draped robes. Create a square 1:1 portrait of this same dignified librarian holding a book, centered, bust fully inside frame, on uniform near-black #080c0d. Render the entire portrait from clearly visible tiny fixed-width ASCII terminal glyphs . : + * # % @ = / arranged on a regular grid, like authentic terminal art, not smooth drawing with overlay text. Restrained monochrome muted cyan #77c9ce highlights and dark teal shadows; no ivory, no purple. Figure edges dissolve into sparse characters toward bottom and sides. Keep face recognizable and stately, no toy. No circles, network connections, labels, words, text headings, UI, cards, borders or architecture. This will be the central illustration inside an HTML agent-memory network diagram with native text around it.
