# Ring — Landing Page Structure

**URL:** `ring.zenod.dev`
**One-line value prop:** One door to all your agents. Message it from anywhere; it knows where things go.
**Competitive edge to land:** multi-agent frameworks make *you* the context bus, copy-pasting between chats. Ring is the opposite: a router already authenticated to all your units, reachable from WhatsApp, Telegram, or the web, that files/posts/runs on your behalf and answers with receipts. The aggregation is the product.

## 2. The problem

- Diagram-as-image: you in the middle, arrows to six agent chats ("today, YOU are the context bus"). Then the flip: Ring in the middle, you holding one thread.

## 3. How it works (3 steps + screenshots)

1. **Wire your units** — screenshot: the **My Units wallet panel** (the product's signature screen — tokens for Zenod, Callisthenes, Epaminon, Phylax, each with imported skills listed).
2. **Pair a channel** — screenshot: WhatsApp/Telegram pairing (via Phylax) or just the web chat.
3. **Say it once** — screenshot: one message routed; the reply carries the unit's receipt.

## 4. Key claims (4 cards)

- **The wallet is the product** — your agent-to-unit tokens in one tenant-scoped panel.
- **Skills, self-described** — add a unit, Ring imports its skill manifest and can route to it. No configuration essays.
- **Any channel** — WhatsApp, Telegram, web chat: same brain, same pairing, same receipts.
- **Suites welcome** — Herald-style composed agents are just machine tenants with their own wallet.

## 5. Show it working (the satisfying demo)

- Looped recording of the golden path: voice note on WhatsApp → transcribed → filed to Zenod → ack back in WhatsApp with the receipt. Then a second beat: "post this" → Callisthenes draft → approval → permalink. Two messages, two different units, zero app-switching.

## 6. What Ring refuses to do (differentiation-by-boundary)

- Short block: owns no channel code, holds no outbound keys, writes no memory — it routes. This is why it composes instead of competing with your tools. (Reads as an anti-lock-in promise.)

## 7. Pricing

- **Hosted — subscription** (with the wallet; unit subscriptions are separate and per-unit).
- **Self-hosted — free**, same image, one tenant.

## 8. FAQ

Do I need all the units? (no — wallet works with any subset) / Can I wire third-party MCP servers? / What does Ring see? (routing metadata; content flows to your units) / Is web chat different from WhatsApp? (no — a channel like any other)
