The problem

Every agent you hire is a brilliant amnesiac.
You are the context bus.

  • You re-explain yourself to Claude, Codex, and every new harness — preferences, projects, history, every session.
  • Every agent wants raw access to your notes, your backlog, your inbox, your Twitter. Give it, and each becomes a junk drawer within a week.
  • Nobody guards your attention. Ten agents means ten streams of "Done!", half of them contradicting each other.
Scattered context across ten agents doesn't scale. Neither does giving them all the keys.
What's new

From a memory agent…

Where we started

Zenod: a self-hosted librarian. One agent, one vault. Evidence in, ideas out, every fact a git commit. Still true — still the foundation.

Where we are

Every valuable thing you own — memory, backlog, attention, outbound voice — now has a gatekeeper: one agent that governs it, keeps it coherent, and answers for it. Any harness can talk to your ring. None can trash it.

Gatekeeper: an agent whose job is to say no on your behalf — so everything else can safely say yes.
Principles

Five rules the whole suite obeys

Everybody reads. One writes. Each domain has exactly one gatekeeper with write authority. Agents ask; they never get raw CRUD.
Discipline as code, not willpower. Schemas, filing rules, and state machines are enforced deterministically — not in prompts, not in hope.
You hold the keys. Plain markdown, in a git repo, in your GitHub, on your server. Export with zero loss. AGPL.
Auditable to the commit. Every memory, every ticket, every send is a commit or a labeled event. `git log` is the audit trail.
Outward needs your word. PRs, tweets, emails — anything irreversible gates on human approval. Internal artifacts flow autonomously.

The ring is open

Any harness can call your Council.
It's already authenticated, trained, and gated.

  • MCP native. Claude, Codex, Cowork, anything — one bearer token, one endpoint, tools like search_memory, ask_brain, store_memory.
  • Your preferences ride along. The ring knows how you like things done; visiting harnesses don't need to be re-taught.
  • Deterministic lanes between governors. Archus↔Epaminon speak in facts, not vibes — four deterministic messages, one rare LLM unblock lane.
  • Agents that want you go through Phylax. No agent talks to you directly. Dedup'd, sequenced, honest ("draft PR #106, unmerged").
Killer demo · 1

Voice note → merged work → filed memory

You send a WhatsApp voice note. "Look into X and fix it." Transcribed, classified, recorded.
Archus files a ticket. Work ticket in its home repo, execution ticket in the queue.
Epaminon runs it with Codex. Outward result (a PR) gates on your approval; internal notes don't.
Phylax tells you once, honestly. One notification, exact state, nothing truncated.
Zenod files the outcome. A cited meaning note lands in your vault — findable by every agent forever.

One voice note in. One commit trail out. That's the whole pitch in 60 seconds of screen recording.

Honesty layer

What we say before HN says it for us

  • "Another multi-agent framework?" No — no framework to learn. It's a running household: opinionated governors over your assets, not a toolkit for building agents.
  • "Too early / pre-alpha?" Correct, and we say so: we are user #1, M0 is shipped with 48 deterministic tests, the rest is public roadmap. Early is the point — the vault format is plain markdown, so betting early costs nothing to exit.
  • "Why not Mem0 / Letta / a memory API?" Their memory lives in their database. Yours lives in your git repo. When you leave, you take everything, with the audit trail.
  • "Greek names are a lot." They're flavor, not homework. You only ever talk to one door: the Council.
