Memory MCP market: where Zenod can win

Memory MCPs are crowded at the desk and empty on the phone. Zenod should own one line: talk on WhatsApp, and every AI remembers it, in files you own.

1. Who plays

Memory is the busiest corner of MCP this autumn. Supermemory's founder wrote on 26 Nov: "memory is hot again, everyone is doing memory". The money and the stars sit on the left of the map: memory layers that developers build into their own apps. The right side, memory for one person, is mostly do-it-yourself: an Obsidian vault or a Markdown repo that Claude Code reads.

2. Where Zenod stands

Zenod sits in the empty corner of the map: memory for one person, in files they own, that fills itself from the phone. Everyone else on the right side expects you to type, or to sit at a computer with a coding agent. Our gaps are reach and public proof.

What only Zenod does

  • ✓ You talk on WhatsApp and it is filed. No one else on the map takes voice from a phone app people already use.
  • ✓ Your exact words are kept for good, beside the summary.
  • ✓ The memory is Markdown in your own GitHub or Google Drive, so Obsidian opens it.
  • ✓ Claude, ChatGPT and Cursor all read the same memory over MCP.
  • ✓ €9 a month, below gbrain at $49 and Basic Memory Cloud at $15 to $19.

Honest gaps

  • ✗ 3 GitHub stars against 4.7k to 120k. The X list threads rank repos by stars, so we are left out of them.
  • ✗ 0 of 10 AI assistants name Zenod. They name Basic Memory, Mem0 and MemoryPlugin.
  • ✗ 3 testers and no one uses it daily yet. There is no public proof.
  • ✗ No benchmark score. Mem0, MemPalace and Supermemory all sell on one.
  • ✗ Listed in 4 of 10 directories. Smithery is closed and PulseMCP is paused.
