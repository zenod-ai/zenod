## 1. What OpenCode Go is, and what its terms allow

Sources read 2026-11-09:

- [opencode.ai/docs/go](https://opencode.ai/docs/go/): plans Go $10/month, Go Plus $40/month, Go Teams $20/member/month; "Go and Go Plus are for workspaces with a single member". Endpoint `https://opencode.ai/inference/go/openai/v1/chat/completions` (OpenAI Chat Completions compatible), models `deepseek-v4.1-flash` and `deepseek-v4-pro`, both behind the workspace privacy setting "Global" region. Metered at $0.15 / $0.60 per M in/out off-peak (cached $0.003), double at peak (01:00–04:00 and 06:00–10:00 UTC weekdays). Monthly allowance for V4.1 Flash $100 on Go ($200 Go Plus); windows: 5 hours 20% of the month, week 50%, month 100%. At the limit requests are blocked; with Console credit, "Extra Usage" falls back to the pay-as-you-go balance. There is no separate Go top-up: a top-up is Console credit used by Extra Usage.
- Same page, "Where can I use it?": "OpenCode Go is designed for OpenCode and other coding agents that produce similar types of requests. Traffic is monitored for abuse that degrades the experience for other users." Clients should "Send typical coding agent traffic", identify with their own user agent and send `x-opencode-session`.
- [opencode.ai/legal/terms-of-service](https://opencode.ai/legal/terms-of-service), effective 2026-11-08: "You will only use the Services for your own internal use, and not on behalf of or for the benefit of any third party". The Services are "OpenCode's website, inference product and hosted software offering", so Go and Console credit both fall under it. Prohibited also: any use that "runs … any processes that run or are activated while you are not logged into the Services". "OpenCode is also free to terminate (or suspend access to) your use of the Services for any reason".

**Verdict.** Hosted Zenod filing, desk, persona and self-reflection runs are server processes for paying customers: third-party benefit, not coding-agent traffic, run while nobody is logged in. Not allowed on Go or Console credit. The risk is Jordi's own Go plan being suspended. Go stays fine for Jordi's own coding and for the team's own test runs (internal use, E15-A6).

**Closest allowed route: DeepSeek's own API**, read 2026-11-09:

- [api-docs.deepseek.com/quick_start/pricing](https://api-docs.deepseek.com/quick_start/pricing): `deepseek-flash` (DeepSeek-V4.1-Flash-1017) cache hit $0.003, cache miss $0.15, output $0.60 per M off-peak; peak doubles, same hours as Go; base URL `https://api.deepseek.com`, OpenAI and Anthropic formats. Fees are "deducted from your topped-up balance or granted balance".
- [Rate limits](https://api-docs.deepseek.com/quick_start/rate_limit): 2,500 concurrent requests for flash per account; `user_id` isolates content safety, cache and scheduling per end user.
- [Error codes](https://api-docs.deepseek.com/quick_start/error_codes): 402 Insufficient Balance when the balance is gone. [GET /user/balance](https://api-docs.deepseek.com/api/get-user-balance) returns `is_available` and the balance.
- [DeepSeek Open Platform terms](https://cdn.deepseek.com/policies/en-US/deepseek-open-platform-terms-of-service.html), effective 2026-04-29, 1.1: "You can integrate the capabilities of the DeepSeek models into various downstream systems, applications, or functionalities … providing services to both internal and external end users." Refunds of unspent balance on request (6.3). Outputs must be disclosed to end users as AI-generated.

So a $10 DeepSeek top-up buys exactly the tokens Go meters, without Go's tenfold allowance, and is allowed. Against OpenRouter today it buys 1.7 to 4.8 times more background work.

## 2. What was built (inactive until the key exists)

Shipped in [#1547](https://github.com/zenod-ai/zenod/pull/1547) (9203bba) and [#1548](https://github.com/zenod-ai/zenod/pull/1548) (551bb7d, the hosted health field). **Deployed:** `cloud.zenod.dev/api/health` reads sha `551bb7d217490343cfaccfbea37df96d46cd94bc` with `"background":{"provider":"off","state":"off"}` (2026-11-09, publish run 42561998865). The route is off as designed: zenod-mt has no `DEEPSEEK_API_KEY` (env names checked through the dokploy wrapper).

- `packages/core/src/llm/deepseek.ts`: DeepSeek base URL, published prices, peak hours and `deepseekCostUsd`.
- `packages/core/src/llm/aisdk.ts`: provider `deepseek` (OpenAI-compatible chat at api.deepseek.com, default model `deepseek-flash`). A fetch seam sends the tenant as `user_id`, asks for usage on streams, maps reasoning effort `none` to `thinking: disabled`, and records each call's real charge (cache hit/miss, peak hours) as `providerCostUsd`.
- `packages/core/src/llm/backgroundRoute.ts`: `withBackgroundRoute` sends filing (classify, compose, reconcile, backlog extraction) and desk work (`work`) to DeepSeek; answers, chat, turn plans and images stay on OpenRouter. Any DeepSeek failure repeats the call on OpenRouter; 401, 402 or 403 parks DeepSeek for 10 minutes. A used-up AI allowance is never retried elsewhere.
- `packages/server/src/backgroundRoute.ts`: host env `DEEPSEEK_API_KEY` (absent = off), `ZENOD_BACKGROUND_ROUTE` per job (`filing`, `desk`, `personas`, `reflection`, each `deepseek` or `openrouter`, default all `deepseek`; `off` turns it off), `ZENOD_BACKGROUND_MODEL` (default `deepseek-flash`), `ZENOD_BACKGROUND_LOW_BALANCE_USD` (default 5). A process-wide balance monitor reads `GET /user/balance` every 15 minutes and logs one `[background] ALERT` line on low or empty and one on recovery.
- `/api/health` gains `background`: `{provider:"off",state:"off"}` today; with the key `{provider:"deepseek", jobs, state: ok|low|empty|unknown, balanceUsd, checkedAt}`. Never the key.
- Runtime: the engine's LLM is OpenRouter wrapped by the background route (then Jev, unchanged); persona runs use DeepSeek with OpenRouter fallback. Same `onBeforeCall` allowance check and feature tags, so caps are unchanged. `reflection` is accepted now and takes effect when self-reflection ships.
- Usage: `GET /api/usage` summary gains `byProvider` (real charge when reported); estimated `cost_usd` for DeepSeek rows uses its cache hit/miss price.

Tests (stubs only): `packages/core/test/aisdk-deepseek-background.test.ts` (pricing and peak, request shape and priced usage, routing per method and per job, fallback and parking, allowance never bypassed), `packages/server/test/backgroundRoute.test.ts` (env parsing, inactive without key, balance alert and recovery, cost per provider), `packages/server/test/backgroundRouteRuntime.test.ts` (persona run on OpenRouter without key, on DeepSeek with it, falls back on 402, stays on OpenRouter when its job says so).

## 4. Switch-over and rollback

1. Jordi opens a DeepSeek account, tops up $10 at platform.deepseek.com and creates an API key (ask raised by the Delivery Manager).
2. The key goes in through a private secret card into `zenod-mt` as `DEEPSEEK_API_KEY` (`dokploy env-set zenod-mt DEEPSEEK_API_KEY --stdin`), then `dokploy deploy zenod-mt`.
3. Check: `cloud.zenod.dev/api/health` shows `background.state: ok` with the balance; new `llm_usage` rows carry provider `deepseek`; a week later compare real costs against section 3.
4. Rollback: remove the key or set `ZENOD_BACKGROUND_ROUTE=off` (or one job to `openrouter`) and redeploy. No data moves.
