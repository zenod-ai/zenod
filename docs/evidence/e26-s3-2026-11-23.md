## Fix (ours): the missing trace

[PR #1756](https://github.com/zenod-ai/zenod/pull/1756) (`packages/server/src/phylaxTenantSettings.ts`, `phylaxUnit.ts`, test in `phylaxTenantSettings.test.ts`, 28 pass): when a message that looks like a link or typed code links nobody, Phylax writes one line:
`[whatsapp][link] code message not matched: shape=<link|typed> reason=<no_pending_code|expired|other_number|number_in_use> sender=<phone|lid|other>`.
No number, code or account; ordinary chat logs nothing; replies are unchanged (root L-6). The next tester who gets a code and does not link shows in `docker logs` as "never sent" (no line) or one of those reasons, and `sender=lid` with `other_number` would show the one case that is worth a code fix (a stranger whose message carries no phone number). It reaches production at the next Phylax roll; zenod-mt gets the same code at the next promote. I did not roll Phylax.
