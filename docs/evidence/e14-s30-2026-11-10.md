## What is counted

| Count | From |
|---|---|
| Runs per helper, on schedule or Run now, done, skipped (nothing new) or failed | one log line per helper run |
| Suggestions, findings and questions each run posted | the same line, from this change on |
| Do it, Change, Not now (with or without a reason), typed feedback, voice note, Bring it back, Got it, Undo, per helper | one `[inbox-tap]` line per tap on a real card, examples left out |
| Cost per helper, the quick index's cost, the memory desk's cost | the run line, the index line, the model meter |
| Read as shown and corrected | one `[read-as]` line each |
| Did each switched-on helper run on schedule | the once-a-day list of switched-on helpers and their next wake, matched against the runs that followed |

Every line names an account, a helper and a button, never what a card or message said. The lines are parsed on VPS1 through the host's read-only `docker logs --since --until --timestamps` form; only the parsed numbers cross to VPS3. His account is told apart by an id kept in a private config, not in this repo. The examples (what each helper wrote) come from the read-only copy of his vault and stay on the private page.
