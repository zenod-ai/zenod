## How Phylax binds a code (the question in the brief)

Before: a code bound a number only when that number had been typed first (`verifyInboundReceipt` matched the stored number and the code). **What we chose:** the code alone binds, and the number is read from the incoming WhatsApp message, so the page never asks for it. Because no number pins the code, the link code is long: `ZEN-` plus 8 characters from a 31-letter alphabet (about 40 bits), valid 30 minutes, derived per request so a retried tap shows the same code. A number another account holds is never moved; sending the code twice is a replay; the same code from a second phone after linking binds nothing. The short `42-otter` codes keep working with a typed number.
