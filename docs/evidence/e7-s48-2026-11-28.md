## Why a new route

The old operator test send (`POST /api/ops/testers/onboarding/test-send`) could not do it. It answers "already sent" for Nox, the first welcome already used its Phylax operationId, and it queues the thank-you email, which the mail hold forbids. PR [#1779](https://github.com/zenod-ai/zenod/pull/1779) (squash `0da564ab`, CI green) adds `POST /api/ops/testers/welcome-once`. It takes the ops token and an account id or sign-in email. It sends the same fixed text once per account ever, keeps the message id, and sends no email. It reached production with the scheduled promote of 5e8b1531 at about 13:50Z.
