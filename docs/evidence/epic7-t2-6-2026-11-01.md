## Change
- `packages/server/src/customerLayer.ts` `startCheckout`: when `checkoutEnabledForOwner` is false (live readiness not ready and the owner is not on the `ZENOD_LIVE_CHECKOUT_TESTER_*` allowlist), a request whose `Accept` includes `text/html` gets a 503 HTML page ("Signup is paused for a moment … Nothing was charged. Please try again a little later." with a mailto contact, the published legal contact `jordi@alpha9.io`, and a link back to Zenod), plus the header `Retry-After: 3600`. It uses the same dark card style as the sign-in page. It shows no check names or internals.
- API and fetch clients (`Accept: application/json`, `*/*`, and `POST /create-checkout-session`) keep the 503 `{"error":"paid signup is not open"}`.
- The allowlist logic (`productionReadiness.ts`) is not touched. Allowlisted owners still go through to Stripe.
