## The rules, and how each holds

| Rule | How | Test |
|---|---|---|
| exact approved text | subject "Welcome to Zenod, here is how to start", body word for word from the desk note | `testerSignupWelcome.test.ts` "is word for word" (full text compared) |
| once per tester, ever | sent record per account and per address in `tester-signup-welcome.json` on the data volume, plus the sender's ledger written before the mark | "sent once, ever", "survives a restart"; `send.test.py` `test_welcome_never_resent_when_its_mark_failed` |
| our own test accounts never get it | tester-marks test accounts filtered in the shared tester read; non-testers and unfinished sign-ups too | "who gets it" (`acct-ops`, `acct-friend`, `acct-pending`, `acct-noworkspace`) |
| one setting switches it off | `POST /api/ops/testers/signup-welcome {"mode":"off"}` (ops token); env `ZENOD_TESTER_SIGNUP_WELCOME` sets the start, default on | "one setting switches it off", "the env setting starts it off" |
| welcome goes first | the timer drains the welcome queue before the thank-you and the next-day email | `test_welcome_goes_before_the_thank_you_and_the_nudge` |
| nobody old gets it late | only sign-ups in the last 7 days are due, which takes in the 13 Nov tester once now | "who gets it" (`acct-old`, 8 days) |
