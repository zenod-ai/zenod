## What changed (looks only, no behaviour change, root L-6)

- **Every screen of the cloud app** now uses the paper style of zenod.dev and the product deck: warm paper ground, one ink, one deep green, Newsreader headings, Instrument Sans text. Buttons are pills (filled green for the main action, ink outline for the rest), cards are flat with one hairline and no shadow, fields have a warm hairline with a green focus, tags are small pills, and the section tabs are a row of words with the open one underlined in green, like the landing's menu. Dark mode uses the same warm near-black paper as the chat (E12-S11), so every tab now matches it.
- The header Z is now the same Newsreader Z as the favicon and zenod.dev. It replaces the older Bodoni tile.
- Stray colours (sky-blue links, a violet memory dot, emerald ticks, amber boxes) now use the green and the warm tones.
- **Favicons**: the cloud app, zenod.dev, /connect and the five legal pages link `favicon.ico` (16, 32 and 48), 16 and 32 PNGs, a 180 apple-touch-icon and the SVG, plus a web manifest with 192 and 512 icons. The leftover `vite.svg` is gone. Before this, `/favicon.ico` and `/apple-touch-icon.png` fell through to the app's HTML page. Browsers and phones that ask for those files never got an icon there, so a cached Vite icon from the early build survived.
- **Health page**: the gate serves those icon files before sign-in, so the sign-in page shows the Z too. Its pages link them.
- The icon artwork is the paper Z (Newsreader, ink on paper) already used by `favicon.svg` since commit 37b81fc6. It is the newest Z and matches the paper style. The E10-R2 directory kit's Bodoni Z under `/brand/` is left untouched, because directory listings link to it.

How it is built: `apps/web/src/index.css` theme tokens (light and dark) plus a new `apps/web/src/zenod-ui.css`. The new file restyles the shared UI parts by their `data-slot`, so every screen picks up the look without touching any screen's logic. The chat and graph keep their own `.zp` rules, unchanged.
