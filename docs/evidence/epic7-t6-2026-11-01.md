## What it is

One read-only command on VPS1 that shows every tester in one table (or JSON), plus a `--check` mode for the Delivery Manager's daily T10 wake. It follows EPIC-6's constraints: internal only (no route, port or key added; it runs over SSH on the tailnet host), and the sources are the ones the S1 inventory lists ([INVENTORY](../health/INVENTORY.md) §3.3). No HTML page was built: the table and JSON cover the T10 check, and a page would add a served port for no extra information.

| Column | Source |
|---|---|
| identity, checkout | `customer-identities.json` (Google subject + email), `customer-accounts.json` |
| stripe, renews, next inv, discount, card | Stripe live, read only: subscription + discounts + promotion code + customer, payment methods, `invoices/create_preview` (a preview: creates nothing). Key read from the running zenod-mt container, never printed |
| whatsapp | zenod-phylax adapter binding state; Phylax tenant settings phone `verified`/`pending`/`none` (number never read out) |
| last Saved, 7d saves | Phylax capture jobs (`wa` = WhatsApp Saved/Captured receipts); `all` = the T2.5 capture index (tenant `tasks.sqlite`) |
| AI $ mtd | tenant `usage.sqlite`, the same sum as `runtime.ts monthToDateSpendUsd`; vs `ZENOD_TENANT_MONTHLY_ALLOWANCE_USD`, shown "no cap set" until E7-A2 |
| units | Phylax period totals vs `ZENOD_PHYLAX_ALLOWANCE_UNITS` |
| errors | failed captures, cap hits (AI-allowance receipts, paused Phylax paid work, `[llm.allowance.exceeded]` log lines), failed billing notices (zenod-mt log) |

Who is a tester: T4's private ledger (`/home/t3agent/.local/state/zenod-testers/live-codes.tsv`, the file `scripts/stripe-testers.mjs issue` writes), matched by promotion code. Until it exists, every live account with a tenant is shown.

## Daily check hook (T10)

```
ssh hetzner_vps_1 tester-watch --check
```

Prints `ALERT <tester>: ...` lines and exits 1 on: a subscription `past_due`/`unpaid`/`canceled`; a renewal within 5 days whose next invoice is not €0 (no extension applied); AI or Phylax usage ≥ 80% of the cap; failed captures, cap hits or failed billing notices in the last 24 h; a ledger code Stripe does not know. Exit 2 if prod cannot be read; 0 and `OK n tester(s), no alerts` when quiet.
