## 4. Other things in Zenod that steer, ask the user or act like agent_team (listed, not changed)

For the delivery manager's review under root L-6 and L-7. None was touched here.

1. **Herald chat approvals** (`packages/server/src/heraldChat.ts`, `heraldLoop.ts`, `heraldLanes.ts`, `herald-loop-panels.tsx`, Settings). Herald parses "approve 1, 2 / reject the rest" from chat and keeps wakes and proposals with a board read model. It is a separate unit (`heraldUnit.ts`), but it lives in this repo and shares the chat chassis. It is a chat command parser, which is what L-6 rules out for Zenod's chat path.
2. **Execution tickets and the Epaminon mesh** (`packages/core/src/taskingPolicy.ts`, `runtime.ts` "Created execution ticket …", reading tickets from Epaminon over the mesh). This is team-desk machinery (tickets, executors) reachable from the runtime.
3. **Agent-ops recognition in filing** (`treePlacement.isAgentOpsReport`, `vault/captureOrigin.ts`). Filing recognises epic, ticket and run ids (`E46-S9`, `T3`, `Run: run_…`, `agent_team`) and folds those captures into `## Ops rollup` lines. It keeps agent traffic out of the tree rather than steering it, but it encodes agent_team's id formats in Zenod.
4. **Built-in alias `agentine ↔ agent team ↔ agent_team`** (`vault/memoryIndex.ts` `BUILT_IN_ALIASES`). Plain search help, kept (section 1). It names agent_team in product code.
5. **Jordi-specific seed tree** (`vault/treeSeed.ts` `AUDIT_TREE_PROPOSAL`, summaries naming Epic Social, Agent Team and EpicSpine) and **coined-name examples** in `engine/treeSubjects.ts` comments. These are hand-picked topics in a shared code path, which EPIC-9 L-1 says roots must not be. It is used only by `zenod tree seed`.
6. **Doctrine lines that still prescribe asking** (`docs/LIBRARIAN-DOCTRINE.md` §"Ask-when-unsure", "Proposal-first", and "Periodic audit … surfaced as proposals"). These are older general rules. With E9-5i, no code path writes proposals to the person.
7. **Entry hook** (`packages/server/src/entryHook.ts`, agent_team E42-S20). This is the sanctioned "new voice note landed" seam: operator-only, off by default. It is in scope of L-7, listed only for completeness.
