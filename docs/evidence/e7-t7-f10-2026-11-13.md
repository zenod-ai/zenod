## What changed

- **Same tools list every round** on models that bind thinking to the tools list (Claude Sonnet, Opus and Haiku 5.5, Fable and Mythos 5.1+, on the Anthropic provider). Each round's limits are now enforced in our code: search first, read before submitting, only submit in the final round. A call outside them returns an `ERROR:` tool result naming what is allowed. `tool_choice` still says required or none; it is not part of what the signature checks. On Sonnet 5.5 a forced choice was already sent as `auto`, so narrowing the tools list had been the loop's only constraint, and that narrowing is what broke. Other providers (OpenRouter, DeepSeek) keep the narrowed lists.
- **The trim and thinking:** T7-F9's per-round trim rewrites an earlier tool result. Thinking made after that message would no longer verify, so it is dropped from the end. Blocks made before it are kept.
- **Paid rounds are recorded:** a provider error mid-answer now writes one `answer` usage line for the rounds that ran, with status `failed` and `answer_round_failed`. The allowance leaves out failed lines, so the tester is not charged. The log also gets one `[answer-round] failed after step=N …` line.
