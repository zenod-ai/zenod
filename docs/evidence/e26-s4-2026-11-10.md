## What happens if it lapses

- `google_drive_vault_oauth` is not advisory, so `/api/public/production-readiness` turns `ready:false` and
  `checkoutEnabled()` closes paid checkout for every new person, the €0 tester code included.
- Existing subscribers and their Drive vaults keep working: the check only gates checkout.
- Only owners on `ZENOD_LIVE_CHECKOUT_TESTER_GOOGLE_EMAILS` / `_GITHUB_IDS` / `_USER_IDS` can still check out.
  The E26-S2 auto-accept flow does not add accepted testers to those lists (only env reads them), so every tester
  accepted after 28 Nov would hit a closed checkout.
- The VPS1 readiness watcher (EPIC-7 T2.3) warns from 2026-11-21 and alerts at expiry.
