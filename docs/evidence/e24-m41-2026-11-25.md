## (c) Cause

Reproduced locally on the real code: `transcribeAudio(<150 s ogg>)` with `ELEVENLABS_API_KEY` set threw `RangeError: The value of "delay" is out of range. It must be an integer. Received 195003.25` at `AbortSignal.timeout` in `transcribeWithElevenLabs`. Phylax's transcriber does not pass a length, so it is probed with ffprobe and is fractional. The A10 tests passed only whole lengths (30, 60 s), so CI never hit it. Long notes would also have failed: every part length is `seconds × bytes / total`, always fractional.

The "not transcribed" Log entry did not happen: the note had 3 of its 5 tries, and the entry comes only after the 5th. With the fix, the 4th try writes the note out, so it is filed as a normal transcribed note.

Tests: 5 new, all fail on main and pass on #1769 (elevenlabsTranscription: whole-ms limit, the 150.0065 s note, a call that never throws, fractional parts; phylaxChannels: a throw names step, provider and code, is retried and shows on health). Full server suite: 2173 passed.
