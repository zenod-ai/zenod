## What #1690 does (3ec90ca0, CI green, merged 17 Nov)
- Each applicant's `?s=<post id>` (or the host of the site they came from) comes from their first application that carried one. A sign-up counts under its application's source, matched by the code it redeemed, or else by its checkout email.
- Our own tests are left out: `isTest`, `?s=TEST`, and test accounts.
- Only the source id is published, never a person. A source must match `[A-Za-z0-9._:-]{1,64}` (`cleanApplicantSource`).
- `definitions.by_source` says what the field means. Test: `publicCounts.test.ts` "counts applications and sign-ups per post source, our own tests left out, never a person (E7-S11)".
