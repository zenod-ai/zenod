## Changes

- Repo, [#1702](https://github.com/zenod-ai/zenod/pull/1702): `scripts/memory-eval/nightly.sh` re-measures an unchanged sha after `ZENOD_REMEASURE_HOURS` (20) instead of 24 h, because the old rule would skip a daily timer. The timer and service are now in the repo (`scripts/memory-eval/zenod-memory-tests.{timer,service}`), so a reinstall keeps the nightly cadence. `docs/memory-test-suite.md` "When it runs" updated.
- vps3: the new timer and service were installed in `~/.config/systemd/user/`. Then `daemon-reload` and a timer restart. `zenod-e22-l4-refresh.timer` was disabled with `--now`, and the four helper-tally units were removed.
- VPS1: `~/.config/systemd/user/zenod-pageviews.timer` changed to `OnCalendar=*:03`, then `daemon-reload` and a restart. The old copy is `~/zenod-pageviews.timer.bak-e24-m20`. The unit's source is zenod-social `scripts/systemd/`. That is another world's repo, so it got a desk note asking it to make the same change ([9e6c84be](https://github.com/zenod-ai/zenod-social/blob/main/desk/inbox/2026-11-18-zenod-zenod-pageviews-timer-is-hourly-now-plea.md)).
