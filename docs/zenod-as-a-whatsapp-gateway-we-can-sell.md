## Goal

Jordi wondered whether Zenod, which already has a WhatsApp gateway (Phylax), could also be sold as that gateway: other agent teams reach their owner on WhatsApp through it. This draft holds the idea until he readies it or says not now.

Goal sentence: Zenod's WhatsApp gateway is something we can sell on its own.

## Serves

- [ ] E13-2 If approved, a first outside agent team sends its owner a WhatsApp message through Zenod's gateway, metered and capped like any tenant.
