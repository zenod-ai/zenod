Ingest pipeline

Every media memory follows the same receipt path.

1 · Preserve

Raw evidence

Store the original artifact in Drive or the configured archive. Record media type, source, timestamp, sender, and immutable handle.

2 · Extract

Text and facts

Transcribe audio. OCR screenshots. Extract PDFs. Use vision where OCR is not enough. Keep extraction output as evidence.

3 · Digest

Meaning pages

File distilled meaning into markdown with citations back to the raw artifact and extraction evidence.

4 · Commit

Git receipt

Return evidence ref, pages touched, commit SHA, artifact URL, and GitHub URLs. No bare acks.

5 · Search

Find it later

Search hits can point to the meaning page, transcript, screenshot extraction, or raw evidence ref.

6 · Ask

Cited synthesis

ask_brain answers from filed meaning and raw evidence with structured sources.
