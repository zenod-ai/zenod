What it is

A guy authenticated to all the other guys.

Ring holds a wallet of agent-to-unit tokens on your behalf — Zenod, Callisthenes, Epaminon, Phylax — plus the intelligence to route. Pure aggregation; it owns no pipes.

The Ring's product is the aggregation, not the pipes.
Key positioning points

Why Ring, in five lines

  • One door. Message your whole Council from any channel; Ring knows who you are and where it goes.
  • The wallet is the product. Your unit tokens live in one tenant-scoped wallet — the "My Units" panel.
  • Skills, self-described. Every wired unit publishes a skill manifest; Ring imports it and routes accordingly. Add a unit, gain its skills.
  • No channel code. Channels live in Phylax; web chat is just another channel. Ring stays pure intelligence.
  • Suites are tenants. Herald or any composed agent is just a machine tenant with its own wallet — no special code, ever.
The multi-tenant config

One Ring container, tenant-keyed wallets.

A customer is a row

One always-on Ring serves every tenant. Pairing tables map senders to tenants; wallets are rows, not deploys.

Standard MCP everywhere

Inbound arrives from Phylax as sender-tagged MCP tool calls; outbound goes to units over their tokened MCP URLs. No bespoke protocol anywhere.

Self-host = same image

The identical container with one tenant, wallet UI included.

In the suite

Where every message finds its owner.

1

A WhatsApp voice note lands at Phylax, is transcribed at the edge, and forwarded sender-tagged.

2

Ring maps sender → tenant, reads the intent, and picks the unit: file it (Zenod), post it (Callisthenes), run it (Epaminon).

3

The unit returns a receipt; Ring acks you through Phylax — one honest voice, with the receipt trail attached.

Boundaries

What Ring owns — and refuses.

  • Owns: the wallet, sender→tenant pairing, routing intelligence, the conversation surface.
  • Never: holds channel credentials (Phylax), writes memory (Zenod), holds outbound keys (Callisthenes), executes code (Epaminon).
  • Routes with receipts. Every hop is a standard MCP call carrying its origin ticket.
