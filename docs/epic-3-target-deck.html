Epic 3 · the whole point, one page

A few containers. Services live on them.
Strangers pay and use them.

The target: each product is ONE container on the VPS, serving ALL its customers. A stranger opens the site, signs in with GitHub, pays, lands in a working dashboard, uses the product. Adding a customer is a database row. Adding a product is one more container.

Login and payment are built ONCE — in the chassis — and every product inherits them. GitHub sign-in → account. Subscribe → Stripe checkout stamped with your user ID → tenant created on that account → dashboard. No unit ever writes auth or billing code again. No claim links, no token-paste logins, no email matching — ever.

Step 5 per product: Zenod — enter model key, ingest a note, see the commit receipt. Callisthenes — connect X (3 credentials + PIN), your agent drafts via MCP, you approve, real permalink on X. Epaminon — submit a task, watch the transcript, download the artifact.

The worker walks this journey in a real browser on the live site, fixes what breaks, walks it again from step 1 — until one clean pass with screenshots. Then Jordi walks the identical journey. Nobody asks Jordi to click anything they haven't clicked. No test suite, however green, means anything while this journey is broken.

The order — three moves, no detours

1 · Finish the Zenod journey (in flight now) — fix the blank Keys page + wire checkout→tenant, walk the journey clean, hand Jordi the URL. Zenod is then a live product taking signups.

2 · Hoist accounts+billing into the chassis — the login/subscribe/user↔tenant code the pilot debugged moves into packages/mcp-chassis as the accounts module. Built once. Every unit inherits it from here on. This is the ONLY infra work left that isn't a product journey.

3 · Stand up Callisthenes — one atomic unit: chassis front (inherited login/billing/dashboard, zero new auth code) + the Python X engine that already works (three-input connect, PIN, drafts-never-send, permalink receipts). Walk its journey clean, hand Jordi the URL. Then Epaminon, then Ring — same recipe, same test, each cheaper than the last.

Success = Jordi buys each product on its public site with a test card and uses it, start to finish, without anyone explaining anything. Everything that does not move a journey toward passing does not get worked on.
