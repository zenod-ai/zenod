The backlog · final design · one rule

"Add this to the backlog."
There are exactly two backlogs, and one question.

Lock 1 · Two doors, period

Life backlog → Archus. Anything else → Epaminon. There is no third write path anywhere in the system. Ambiguity doesn't pick a door — it asks you one question.

Lock 2 · The pen is chained

Archus's write tool has no repo field — obsidian-brain is a constant in code. He can be confused all day; the confusion has nowhere to land. Epaminon's route requires an explicit repo name, or it must ask.

Lock 3 · No unverified "done"

Every write is read back from GitHub before anyone says success. Failure says FAILED, with the real error. A daily canary proves the path each morning — through Phylax, not through hope.

Why this is forever: nothing here depends on an AI behaving. The doors are code, the pen is chained by code, the truth is checked by code. The models only ever pick between two safe options — and when they can't, they ask you.
