Epaminon.

The one who gets it done. Hand him a ticket; workers with budgets run it; a completion event tells you when it's finished.

Epaminon owns execution: async tools, a ticket for every job, and workers sized to the work with hard budgets. Long jobs never hold the wire — you get a ticket receipt now, a completion event later, traceable end to end.

Ticket in, event out
Every dispatch returns a ticket ID immediately; completion arrives carrying the same ID.
Workers with budgets
Each job gets its own worker, sized and capped — no runaway runs.
Traceable to the origin
Every ticket carries the request that spawned it, so receipts trace all the way back.
