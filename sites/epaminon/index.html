What the hosted worker includes

Epaminon is the cloud execution unit for jobs that are too long or too stateful for a chat window. It keeps the MCP surface small and gives each run a durable receipt.

Prompt and effort level
Submit the task in plain text, then pick a bounded effort profile for the worker.
Prewired MCP servers and skills
Memory, GitHub, repo context, and approved skill packs are configured before the worker starts.
GitHub artifacts
Code work can land as a branch, commit, issue note, pull request, or linked evidence bundle.
Status you can poll
Each checkout and run returns a receipt id that leads back to status, transcript, and setup.
